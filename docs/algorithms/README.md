# HARFlow Algorithms Reference

This directory documents deterministic algorithms implemented across HARFlow analytical crates:

1. **Smart Traffic Classification (`harflow-classifier`)**: Rule-based categorization into 13 traffic categories (`API`, `Authentication`, `Analytics`, `Advertising`, `Telemetry`, `Static Assets`, `Images`, `Fonts`, `CSS`, `JavaScript`, `Media`, `Documents`, `Other`) with CORS `OPTIONS` preflight detection, custom `CleanerConfig` / `CustomCleanerRule` support, logical filtering preserving raw normalized entries, and explainable rule reasons.
2. **Endpoint Discovery (`harflow-endpoints`)**: Two-pass path clustering (`discover_endpoints_with_overrides`) preserving static small-digit version segments (e.g. `/v1/`, `/api/2/`), detecting UUID, numeric, prefixed-token, and high-cardinality sibling slugs keyed with their preceding path segment, inferring singularized parameter names, optional/typed query parameters, status code distributions, and priority pagination style (`Cursor > PageNumber > OffsetLimit`) with confidence scores.
3. **Schema Inference (`harflow-schema`)**: Recursive multi-observation JSON schema inference (`infer_schema_from_samples`, `infer_endpoint_schemas`, `diff_schemas`) distinguishing absent vs `null` (`nullable`) vs optional fields, empty arrays (`unknown`), integer+number widening, conservative finite enums, union types, nested objects, and schema drift diffs.
4. **Dependency Detection (`harflow-dependencies`)**:
   - **Per-session Chronological Timeline & Extraction**: Strictly isolates timelines per `sessionId` sorted by `(startedDateTime, orderIndex)` and extracts typed candidates across all 8 `ValueLocation` variants (`Path`, `Query`, `Header`, `Cookie`, `Body`, `SetCookie`, `ResponseHeader`, `ResponseBody`), including redacted secret fingerprints (`harflow-security::parse_redacted_marker`).
   - **Linear $O(N)$ Forward Index & Transformations**: Matches consumers only against strictly preceding producers ($T > 0$) using fixed-capacity forward hash buckets supporting `Identity`, `PrefixSuffix` (`access_token -> Authorization: Bearer`, `Location#segment -> Path/Query/Body`), `UrlEncoding`, `Base64`, and `JsonExtract`.
   - **False-Positive Guardrails**: Filters pre-existing client values echoed by the server, rejects weak scalar constants/config keys (`limit`, booleans, single-digit/small ints without ID alignment, and short pure-alpha non-ID strings), penalizes low-entropy/frequently repeated strings in uniqueness scoring $U$, and penalizes single-session coincidences contradicted by sibling sessions.
   - **Confidence Calibration**:
     $$C = 0.30V + 0.20T + 0.20U + 0.20R + 0.10S$$
   - Mandatory temporal ordering gate ($T > 0$) before any dependency can be marked `confirmed` or `likely`.
   - Thresholds: `>= 0.90` (`confirmed`), `0.65–0.89` (`likely`), `< 0.65` (`unknown`), manual override (`user_confirmed`).
5. **Graph Cycle Analysis (`harflow-graph`)**: Supports 5 graph perspectives (`Endpoint`, `RequestDependency`, `AuthFlow`, `SessionTimeline`, `DataFlow`) and bidirectional leaf-peeling (`analyze_graph_cycles`) distinguishing benign endpoint pagination self-loops from request-level dependency cycle contradictions (`DEPENDENCY_CYCLE_CONTRADICTION`).
6. **Session Intelligence & Multi-HAR Comparison (`harflow-sessions`)**: Detects `Bearer`, `CookieSession`, `Csrf`, `ApiKey`, `OauthLike`, and custom signature headers; tracks login/refresh endpoints, redacted fingerprint rotations, `401`/`403`/`expires_in` signals, and strict `auto_refresh_eligible` proofs; compares sessions for shared vs session-only endpoints, `Constant` / `SessionScoped` / `RequestVolatile` parameter variability, corroborated dependencies, auth differences, and schema drifts.
